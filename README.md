# MAIT Buddy – Personalised Chatbot for MAIT Students

## 1. Project Name
**MAIT Buddy: Personalised Chatbot for MAIT Students**

## 2. Overview
MAIT Buddy is a student-focused chatbot designed to make it easier for students of Maharaja Agrasen Institute of Technology (MAIT) to access useful college-related information from one place.

Students often need to look for information about college activities, academic resources, campus facilities, and other student-related queries across different sources. MAIT Buddy aims to simplify this process by providing a convenient, interactive interface where students can seek assistance and find relevant information.

The project focuses on improving the student experience by making college information more accessible, reducing the effort required to find answers, and providing a centralised digital platform for student support.

## 3. Tech Stack

The project uses the following technologies and tools:

- **Next.js:** React-based framework for building the web application.
- **React:** For developing interactive and reusable user interface components.
- **TypeScript:** For writing structured, type-safe JavaScript code.
- **Tailwind CSS:** For styling and creating a responsive user interface.
- **Radix UI:** For accessible and reusable interface components.
- **Lucide React:** For icons and visual elements.
- **Vercel:** For deployment and hosting integration.

## 4. Key Features

- **Student-Focused Assistance:** Designed around the information needs of MAIT students.
- **Interactive Chatbot Interface:** Provides a conversational way for students to interact with the application.
- **Centralised Information Access:** Aims to make relevant college-related information easier to find.
- **User-Friendly Interface:** Provides a clean and accessible interface for students.
- **Modern Web Architecture:** Built using Next.js, React, and TypeScript for maintainable development.
- **Scope for Future Enhancements:** Can be extended with verified college FAQs, academic resources, campus information, and additional student-support features.

## 6. Setup Instructions

### Prerequisites
- Node.js installed on your system.
- Git installed on your system.
- npm or pnpm package manager.

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/Sakshi05131/MAIT-CHAT-BOT.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MAIT-CHAT-BOT
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

   Alternatively, if using pnpm:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   `http://localhost:3000`

### Production Build

To create a production build, run:

```bash
npm run build
```

To start the production server after building, run:

```bash
npm run start
```

If the application requires environment variables or external API credentials, configure them in a local `.env.local` file according to the project's implementation. Do not commit secret keys or credentials to GitHub.
